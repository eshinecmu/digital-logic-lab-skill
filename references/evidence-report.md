# 证据处理与报告

## 在执行前安排证据

按课程实际要求建立检查点。区分课程必需与为说明结果而建议的截图，不能把建议强加成提交门槛。

| 类型 | 应保留的有效信息 |
|---|---|
| 原理图 | 完整逻辑连接、输入输出标签、必要的状态值 |
| 仿真波形 | 信号名、显示进制、时间刻度、足够覆盖测试用例的区间 |
| 编译/自检 | 测试对象、PASS/FAIL、实际错误或警告上下文 |
| 硬件下载 | 目标器件、Programmed 等实际状态、必要的编程文件标识 |
| 板卡实拍 | 相关开关/按键和 LED、可识别标签、对应输入组合 |

物理步骤由用户完成时，提前说明拨哪个开关、是否按住按键、拍摄范围及需回复的状态值。照片不能证明的输入组合保持未知；高阻态不能仅凭 LED 亮灭判定，结合仿真或符合实验要求的测量。

## 图片处理

先看原图再裁剪。按用户授权使用确定性图片裁剪/旋转工具，或 Word 原生裁剪和旋转，禁止以生成式重绘替代实验截图。原图保留，衍生图另存；只处理方向、取景和展示尺寸，不改变电路连线、数值、灯态或错误信息。

裁剪范围按每张图的有效内容决定，不能统一盲裁固定比例。波形不能裁掉信号名或时间轴；原理图不能裁断连线；板卡不能裁掉用于判定输入输出的器件。无关桌面和大块空白可移除，但不能用裁剪隐藏影响结论的错误。若有效内容被过多空白分隔，优先在软件中调整布局重新截图；若分为多个细节图，应明确图注对应同一原始画面，避免误导性拼接。

检查裁剪后的可读性、方向及边界。缺失、模糊、曝光过度不能靠猜测补全，标注需要补拍的具体区域。

## 报告更新

- 先读取最新报告及模板，保留学号、姓名和已有正确内容；创建可辨识的新版本，避免编辑过时副本。
- 用小标题组织目的、原理、建模、测试、结果和问题处理，具体结构服从模板。代码从实际源文件提取。
- 每张图有实验名称、测试条件及结果说明，图号、正文引用随插入更新。
- 理论预期、工具实测、用户确认分别表述；不把尚未下板的模块写为上板通过。
- 根据证据索引替换对应旧图，不凭图片顺序或固定段落号盲替换。更新所有受影响的结论和待补项。
- 最终检查不应残留已完成项的“待补”；真正缺项不能仅删除占位文字伪装完成。

按要求输出可编辑文档和/或 PDF。确认文件重新打开，检查渲染后的相关页面：图片方向与裁剪、字迹、分页、表格和图注。不能仅凭 DOCX 能解压就称排版已验证。PDF 导出不可用时交付编辑版并明确尚缺 PDF，不改扩展名伪装导出。
