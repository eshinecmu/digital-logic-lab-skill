# 同济数字逻辑课程示例

来源：用户提供《数字逻辑实验提交流程.pdf》第 1 页，2026-10-10 读取。仅作为该规范适用时的课程规则；新文档可能修订，须核对。

- 每个小实验一个 ZIP，直接把文件放在 ZIP 根目录。
- ZIP 命名：`学号-姓名-实验序号.zip`。
- Logisim 原理图放在每次实验的第一个小实验 ZIP 中，通常为实际 `.circ` 文件；不能用截图代替可编辑原理图，除非课程另有说明。
- Verilog 文件名可按命名规范调整，文件内部模块名必须与实验指南一致。
- 实验报告为 PDF，命名 `学号-姓名-实验序号.pdf`，提交到课程 Canvas；大实验报告编号与小实验编号分别核对。
- 每次实验三次提交机会。QD 排队、CE 编译错误、AC 正确、WA 答案错误。

实验 6.1 的五项：

| 编号 | 顶层 | 必交内容 |
|---|---|---|
| 6.1_1 | logic_gates_1 | 设计 .v、对应 _tb.v、对应 .bit、Logisim 原理图 |
| 6.1_2 | logic_gates_2 | 设计 .v、对应 _tb.v、对应 .bit |
| 6.1_3 | logic_gates_3 | 设计 .v、对应 _tb.v、对应 .bit |
| 6.1_4 | three_state_gates | 设计 .v、对应 _tb.v、对应 .bit |
| 6.1_5 | extend | extend.v、extend_tb.v |

不得由此推断其他实验也是五项或都需要 bit。Logisim 是这里第一包的附加材料，不单独算第六项。
